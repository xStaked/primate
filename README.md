# Primate — Landing (Astro)

Boilerplate Astro para la landing de Primate.

## Comandos

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # build + check
pnpm preview
```

## Estructura

```
public/
  favicon.svg
  robots.txt
src/
  components/ Navbar.astro Hero.astro Footer.astro
  layouts/ BaseLayout.astro
  pages/ index.astro
  styles/ tokens.css global.css
```

## Siguiente paso

Pasa el manual de marca y se aplica en `src/styles/tokens.css`:
colores, tipografías, radios y espaciados. Sin tocar componentes.
